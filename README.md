# 🍸 Topside Tavern – Interactive Landing Page

An elegant and dynamic landing page for **Topside Tavern**, featuring smooth animations, a 3D background, and modern web styling. Built using **HTML**, **CSS**, **JavaScript**, and **Three.js** to deliver an immersive, interactive experience.

---

## 🚀 Features

- ✨ **3D animated background** rendered with Three.js  
- 🎨 **Stylish responsive layout** with a sleek navigation bar  
- 🥂 **Menu page integration** for visitors to explore offerings  
- ⚙️ **GSAP-powered animations** for smooth visual effects  
- 📍 **Footer with business details** (location, contact, and credits)

---

## 🧱 Project Structure

Topside-Tavern/
│

---

## ⚙️ Technologies Used

- **HTML5** – Semantic structure  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Interactivity and animation logic  
- **Three.js** – 3D rendering for the animated background  
- **GSAP (GreenSock Animation Platform)** – Smooth and performant animations
